# Project Guidelines & Rules

## Output & Artifact Standards
- **Planning**: Whenever planning is performed, always output the plan into an implementation plan artifact (`implementation_plan.md`) in the artifact directory, with `RequestFeedback: true` enabled so the user is provided with a 'Proceed' button.
- **Reviews & Findings**: For code reviews, audits, architectural analyses, diagnostic findings, or reports, always record them into dedicated markdown artifacts (`UserFacing: true`), providing structured documentation.
